## [0.1.0] - 2026-02-27


### Рефакторинг

- Метод InitInfoBase был переработан для улучшения проверки строки подключения и удаления ненужных async/await. Класс InfoBasesReader был удален. DebuggeeProcess и MetadataProvider были обновлены для более эффективной обработки строк подключения.


### Документация

- Обновлен README.md для улучшения описания адаптера отладки 1С, добавлены требования и инструкции по сборке и запуску


### Обслуживание

- Обновлен проект для работы с .NET 8.0 и улучшены проверки на допустимость значений NULL в классах AttachDebugTargetArguments и DebugConfiguration

- Добавлен workflow GitHub Actions для автоматической сборки и выпуска проекта

- Добавлен ввод версии для ручного запуска workflow и улучшена обработка тегов в процессе сборки и выпуска
